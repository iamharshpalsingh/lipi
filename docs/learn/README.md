# LiPi seekho: poora course (Hinglish)

Ye course **zero se** shuru hota hai. Pehle kabhi programming nahi ki? Koi baat nahi. Har chapter me samjhaane wali baatein, chalne wale examples, **exercises aur unke jawab**, aur teachers ke liye tips hain.

Course ka har code example test kiya gaya hai: LiPi ka test suite har example ko chala ke check karta hai ki output wahi aata hai jo yahan likha hai.

**LiPi ke creator:** LiPi ko **Harsh Pal Singh** ([@iamharshpalsingh](https://github.com/iamharshpalsingh)) ne banaya hai. Unka sapna: ek aisi language jo seekhne me aasaan ho, par jisse website, backend, database se lekar aage mobile, desktop aur AI tak sab kuch bane.

## Kaise padhein

1. **Har example khud type karo.** Copy-paste mat karo, type karne se yaad rehta hai.
2. Har chapter ke **"Khud karo"** exercises pehle khud karo, phir **"Jawab dekho"** kholo.
3. Galti ho to **error ka Hint padho**. LiPi batata hai kya karna hai.
4. Naya idea try karna ho to terminal me `lipi` likho (interactive prompt).

**Shuru karne se pehle:** LiPi install hona chahiye (`lipi --version` chala ke check karo). VS Code aur LiPi extension ho to aur achha.

## Teachers ke liye: 8 hafte ka plan

| Hafta | Chapters | Class ka goal |
|---|---|---|
| 1 | 1, 2, 13 | pehla program; "LiPi kyun" ki demo |
| 2 | 3, 4 | faisle aur loops; FizzBuzz challenge |
| 3 | 5 | marks list ka report card program |
| 4 | 6, 7 | functions; "error hunt" game |
| 5 | 8, 9 | apna type; group project in modules |
| 6 | 10 | counter app, to-do app, apni website |
| 7 | 11 | apni API aur database |
| 8 | 12 | final project + presentation |

**Har class ka format (1.5 ghante):**
- 10 min: pichhli class ka recap (2-3 sawaal)
- 30 min: naya concept, board pe example, live coding
- 40 min: students exercises karein, teacher ghoom ke help kare
- 10 min: ek student apna solution dikhaye

**Tips:**
- Galti ko normal banao. LiPi ke errors sikhaane ke liye bane hain; students ko unhe zor se padhne do.
- Har chapter ke end ka **"Yaad rakho"** table class ke end me revise karo.
- Jaldi khatam karne wale students ko exercises ke "challenge" version do.
